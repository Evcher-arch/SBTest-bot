# Contract: заглушка систем (порт 8040)

Один сервис имитирует REST API пяти систем. Вызывающие: MCP-серверы (системы),
индексатор (портал документации), ведущий показа (пульт и карточки).

Все методы систем требуют `Authorization: Bearer <JWT>`. Права применяет заглушка:
это единственное место, где решается, можно ли сотруднику видеть объект. Из токена
заглушка берёт только `sub` и `role`; руководителя и подчинённых она определяет
по своей таблице сотрудников, а не по полям токена.

## CRM — `/crm`

| Метод | Назначение | Права |
|---|---|---|
| `GET /crm/clients?name=&inn=` | поиск клиентов | только свои и подчинённых |
| `GET /crm/clients/{client_id}` | карточка клиента | ответственный, его руководитель |
| `POST /crm/clients/managers` | ответственные по списку `client_ids` | только `recs-service` |

## Биллинг — `/billing`

| Метод | Назначение | Права |
|---|---|---|
| `GET /billing/invoices?client_id=&status=&from=&to=` | счета клиента | как у клиента |
| `GET /billing/invoices/{number}` | счёт с оплатами | как у клиента |
| `GET /billing/invoices/select?status=&due_before=` | выборка по всем клиентам | только `recs-service` |

## Service-Desk — `/sd`

| Метод | Назначение | Права |
|---|---|---|
| `GET /sd/tickets?role=&status=&employee=` | обращения сотрудника | свои; подчинённого — руководителю |
| `GET /sd/tickets/{number}` | карточка с историей | автор, исполнитель, их руководитель |
| `GET /sd/ticket-types` | типы обращений и их поля | любой сотрудник |
| `POST /sd/tickets` | создание; заголовок `Idempotency-Key` обязателен | любой сотрудник, автор — из токена |
| `GET /sd/tickets/select?idle_days=&due_within=` | обращения без движения | только `recs-service` |

`POST /sd/tickets` проверяет обязательные поля типа; повтор с тем же ключом
возвращает существующее обращение с кодом 200 вместо 201.

## Календарь — `/calendar`

| Метод | Назначение | Права |
|---|---|---|
| `GET /calendar/events?from=&to=` | встречи владельца токена | только свои |
| `GET /calendar/events/select?date=&users=` | встречи сотрудников на дату | только `recs-service` |

## Портал документации — `/confluence`

Вызывает только индексатор с сервисным токеном `role: indexer`; токен сотрудника
получает `forbidden`. Сотрудники читают регламенты через поиск, где действует
фильтр по группам.

| Метод | Назначение |
|---|---|
| `GET /confluence/pages` | список: `page_id`, `version`, `updated_at`, `acl_updated_at` |
| `GET /confluence/pages/{page_id}` | страница целиком с `body` и `allowed_groups` |

## Карточки — `/ui`

HTML-страницы без авторизации, на них ведут ссылки из ответов помощника (FR-031):
`/ui/clients/{id}`, `/ui/invoices/{number}`, `/ui/tickets/{number}`,
`/ui/pages/{page_id}`. Демонстрационное упрощение: карточки открыты, потому что
в стенде нет входа в системы через браузер.

## Пульт ведущего — `/admin`

Без авторизации, доступен через Swagger UI заглушки (`/docs`).

| Метод | Назначение |
|---|---|
| `POST /admin/reset` | вернуть данные из `seed/`, сбросить рекомендации, переиндексировать, очистить историю диалогов и черновики (оркестратор), роли и токены (бот); ответ — что сброшено по каждому сервису |
| `PATCH /admin/invoices/{number}` | изменить `due_date`, `status`, добавить оплату |
| `PATCH /admin/tickets/{number}` | изменить `status`, `assignee_id`, `updated_at`, `due_at` |
| `PATCH /admin/pages/{page_id}` | изменить `body` или `allowed_groups` |
| `POST /admin/events` | добавить встречу |
| `POST /admin/outage` | `{system, enabled}` — имитировать недоступность системы |
| `GET /admin/state` | сводка: число объектов, включённые отказы |

`/admin/outage` нужен для приёмочного сценария истории 2 (система недоступна):
методы выбранной системы отвечают 503 и `unavailable`.

## Ошибки

| HTTP | `code` | Когда |
|---|---|---|
| 400 | `invalid_input` | неверные параметры, не заполнено обязательное поле |
| 401, 403 | `forbidden` | нет токена, токен просрочен, объект недоступен сотруднику |
| 404 | `not_found` | объекта нет |
| 503 | `unavailable` | включён отказ системы |

Порядок проверки: сначала существование, затем права. Поэтому чужой существующий
объект даёт `forbidden`, а несуществующий — `not_found` (FR-012).
